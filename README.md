# Bayonetta - More Than a Woman

What if Bayonetta were the cover star of a Vogue editorial?

This conceptual project explores that possibility by bringing the iconic witch from the games into the world of fashion, reinterpreting her aesthetic, personality, and presence through the visual language of the magazine.

A fictional collaboration between Vogue and Bayonetta, created exclusively as a visual study and portfolio project, with no official affiliation with PlatinumGames or Vogue.
